4. Predicted Optimum Conditions

6. Export Report

Save the plan, measured data, predicted optima, model statistics and plots. If the PDF libraries are unavailable, the browser print dialog opens; select Save as PDF. For factor names using non-Latin scripts, use browser Print for full font support.
